Privacy

Effective September 27, 2026.

MCP Here doesn't collect, send, sell or share any information about you or the sites you visit. There are no accounts, analytics or ads. It works entirely in your browser.

What it reads

To tell you whether a site has an MCP server, the extension reads the address of https pages you open. It uses that address in your browser only. It never reads page content, form fields or passwords.

What it stores on your device

  • A list of known MCP servers, grouped by website. This is public data, the same for everyone.
  • For sites you visit, the result of checking that site for a server. It's saved under a scrambled (hashed) key rather than the site's name, and cleared out once it's more than a week old.
  • For sites that have a server, whether you've already seen or hidden the corner button. This is also hashed.
  • Which app you last picked (for example, Claude Code). Chrome syncs this setting across your browsers if you use Chrome sync.

Network requests

  • To the site you're on: requests for its public /.well-known discovery files, at most once a week per site, without cookies.
  • To GitHub Pages: once a week, a download of the public server list from moizahmedd.github.io. GitHub may log the request as described in its privacy statement.

Nothing else is sent anywhere.

When you click

Adding a server copies a command to your clipboard, or opens the app you chose (Cursor, VS Code and others) with the server's details. Setup guides and Claude's connector settings open in a new tab.

Questions

Open an issue on GitHub. The source code is public, so you can check all of this there.
